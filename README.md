# Path One

Electron + 内核 + React Soft Tonal 的精简 Windows 线路客户端。

给完全不懂技术的人：装好打开 → 填端口 / 账号 / 密码 → 打开「浏览器模式」。没有节点列表，服务器和协议都是固定的。

**给最终用户的完整说明书见 [GUIDE.md](./GUIDE.md)**（与应用内「使用说明」一致）。

---

## 先记住这几句

1. 只运行 Path One，不要乱改安装目录里的文件。
2. 程序开着才有效；退出后线路断开。
3. 你只要填三项：**端口、账号、密码**。服务器固定 `10.0.0.101`，协议固定 SOCKS5。
4. 凭据是个人的，不要分享。

## 1. 这是干什么的

Path One 打开后，符合条件的访问会走一条已配好的线路。国内常见网站和 `10.x` / `192.168.x` 等本地网段会尽量直连。

你不用选节点、不用改服务器、不用懂协议。

---

## 2. 你会拿到什么

开通通知里至少有（每个人不同）：

```text
端口：一串数字
账号：一串字母数字
密码：一串字符
```

若还写了地址 / 协议：Path One 里都不用管。只填端口、账号、密码。

---

## 3. 安装与打开

1. 从发放方指定位置下载安装包或解压包。
2. 安装（或解压）后打开 **Path One**。
3. 杀毒拦截时选允许 / 信任。

侧栏只有四项：首页、使用说明、系统服务、内核日志。

---

## 4. 第一次：填三个空

1. 打开「首页」。
2. 粘贴端口、账号、密码。
3. 点「保存账号」。
4. 打开「浏览器模式」开关。

没有「选节点」「填服务器」「选协议」步骤。

---

## 5. 日常怎么开

| 你想干什么 | 怎么做 |
| :--- | :--- |
| 主要用浏览器 | 打开「浏览器模式」 |
| Git / 命令行 / 找不到代理设置的软件 | 先在「系统服务」装好并启动服务，再打开「全局模式」 |

程序需要保持运行（可最小化）。

---

## 6. 怎么确认已经通了

1. （可选）打开前访问 `https://ip-api.com`，记下 Country。
2. 打开浏览器模式后刷新同一页。
3. 国家/地区应与开通说明一致。
4. 备用：`https://ip.sb`、`https://ifconfig.me`。
5. 国内站和本地系统应仍能打开。若网页全挂：点「救急：关系统代理」。

---

## 7. 关掉、救急、重置

| 想做的事 | 操作 |
| :--- | :--- |
| 正常用完 | 关掉浏览器模式，或退出 Path One |
| 网页突然全挂 | 首页「救急：关系统代理」 |
| 内核异常 | 「重启内核」或看「内核日志」 |
| 账号填错 | 改三项再保存 |

---

## 8. 常见问题

**要不要填服务器 IP？** 不要，已固定。  
**要不要选节点？** 不要，没有节点列表。  
**浏览器模式下 Git 不行？** 正常，改用全局模式（需系统服务）。  
**可以和其他代理软件一起开吗？** 不建议，容易抢端口。

求助时请带：开通通知截图、Path One 窗口截图、检测页截图、当前是浏览器还是全局模式。

## 9. 开发者

技术栈：Electron 33、electron-vite、React 18、Tailwind Soft Tonal、自带内核。

```bash
pnpm install
pnpm dev            # 开发预览实例
pnpm test
pnpm build:unpack   # 生产：只打 dist/win-unpacked（无安装包）
```

发放物就是 `dist/win-unpacked` 整个文件夹（可再打成 zip）。双击其中的 `path-one.exe`。

- 固定上游：`src/shared/path-line.ts`（`10.0.0.101` / socks5 / 节点名 Path）
- 界面只暴露三项凭据 + 浏览器/全局开关
- 生产 unpack 使用正式身份 `com.pathone.app`（不是预览）
- 仅 `pnpm dev` 默认进预览：`com.pathone.app.preview`
- 内核文件名：`resources/binaries/core.exe`（界面与文档只称「内核」）
