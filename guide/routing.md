# 路由分流

规则自上而下匹配，先命中先生效。

## 直连规则（固定）

- 包含本地网段（10 / 172 / 192 / 127）、私网、国内 IP。
- **只读**：不可编辑、不可删除、不可关闭。

## 自定义规则

- 位于「直连」与「兜底」之间。
- 可添加：域名后缀、关键词、IP 网段、进程名、GeoSite、GeoIP。
- 目标可选：线路 (PROXY)、直连 (DIRECT)、拦截 (REJECT)。
- 可拖动排序、启用 / 关闭、删除。
- 修改后约 0.4 秒自动保存并热重载。

## 兜底规则（固定）

- 类型 `MATCH`，目标 `PROXY`：上面都未命中的流量走线路。
- 固定，不可改。
