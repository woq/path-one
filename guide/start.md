# 快速开始

本地端口 `8888`。先填账号，再开模式。

## 四步上手

1. 解压发放包，双击 `path-one.exe`。
2. 杀毒拦截时选择允许或信任。
3. 在左侧「账号」填写开通通知中的端口、账号、密码并保存；可用「测试国内 / 国外」。
4. 打开「浏览器模式」。需要 Git / 命令行时，再开「全局模式」（须先启动系统服务）。

## 左侧导航怎么用

- **操作**：账号、浏览器模式、全局模式、路由分流、系统服务、内核日志 —— 日常点这里。
- **说明**：快速开始、确认已通、常见问题 —— 短文，按需打开。
- 每个操作页都有「本页说明」，与当前功能对照即可。
