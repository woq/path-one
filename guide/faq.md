# 常见问题

**账号填哪里？**  
「账号」页只填端口、账号、密码。

**浏览器模式下 Git 不通？**  
到「系统服务」启动服务后，再打开「全局模式」。

**直连规则能改吗？**  
不能。仅「路由分流」里的自定义规则可编辑。

**本地端口是多少？**  
固定为 `8888`。

**测试国外失败？**  
确认已保存账号，并已打开浏览器模式或全局模式，内核为运行中。

**密码含特殊符号？**  
整段复制粘贴即可。
