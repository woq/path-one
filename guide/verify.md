# 确认已通

## 推荐步骤

1. （可选）打开前访问 `https://ip-api.com`，记下 Country。
2. 在「账号」保存信息，点「测试国外」看结果。
3. 打开「浏览器模式」，刷新检测页；国家 / 地区应与开通说明一致。
4. 备用：`https://ip.sb`、`https://ifconfig.me`。
5. 国内站与本地系统应仍可访问。若网页全挂：到「浏览器模式」点「救急：关系统代理」。

## 现象对照

| 现象 | 处理 |
| :--- | :--- |
| 检测页地区未变 | 确认程序在运行且浏览器模式已开 |
| 提示先保存账号 | 回「账号」页填写并保存 |
| 测试国外失败 | 已保存账号 + 已开模式 + 内核运行中 |
| 网页全挂 | 救急关系统代理 |
| 仅 Git / 命令行不通 | 系统服务启动后开全局模式 |
| 全局模式开不了 | 到系统服务页安装 / 启动，权限点「是」 |
